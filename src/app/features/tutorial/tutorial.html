Como configurar o Argos?

1. Configuração do projeto

Adicione o arquivo argos.config.ci.json na raiz do projeto em que você deseja rodar a avaliação de acessibilidade.

baseUrl: URL base do seu site.

routes: Rotas que devem ser avaliadas.

projectId: ID do projeto que você deseja avaliar.

*É necessário criar um projeto no Argos para obter o ID.

2. Adicionando na pipeline

Adicione os seguintes steps no arquivo de configuração .yml do seu projeto de CI/CD.

3. Commite os arquivos e execute a pipeline CD

Ao final da avaliação, o Argos irá gerar um relatório de acessibilidade e disponibilizá-lo em seu dashboard.

4. (opcional) Rodar via CLI

Caso deseje rodar a avaliação de forma local, você pode instalar o pacote na raiz do projeto e executar o comando npm run audit.
