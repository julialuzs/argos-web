Como usar o Argos?

Escolha o modo de avaliação. Todos os caminhos geram relatório no mesmo projeto.

Na aplicação Integração com pipeline CI/CD Linha de comando

Use o Argos pela interface: cadastre o projeto, execute a análise em Relatórios e acompanhe o resultado no dashboard. Não é necessário arquivo de configuração nem pipeline.

  1. 1

    Crie ou selecione um projeto

    Informe o nome, a URL base e as rotas que devem ser avaliadas. Esses dados ficam salvos no Argos e são usados na execução.

  2. 2

    Abra Relatórios

    Com o projeto selecionado, a aba Relatórios mostra as análises já executadas.

  3. 3

    Clique em "Executar análise"

    O avaliador usa a URL e as rotas cadastradas no projeto. A execução pode levar alguns minutos, mas a lista atualizará sozinha quando o relatório ficar pronto.

  4. 4

    Veja o resultado no detalhamento do relatório e no dashboard

    Pontuação, erros, avisos ficam disponíveis no detalhamento do relatório, e a evolução entre execuções é mostrada no dashboard.

Integre o avaliador à pipeline de CI/CD do repositório. A cada deploy, o Argos gera um relatório e envia para o projeto correspondente na aplicação.

  1. 1

    Crie o projeto no Argos e copie o GUID

    O projectId da configuração é o GUID público do projeto, não o identificador numérico interno. Copie-o na lista de projetos ou pelo botão abaixo.

  2. 2

    Adicione o arquivo de configuração

    Na raiz do repositório, crie argos.config.ci.json com a URL base, as rotas e o GUID do projeto.

    baseUrl - URL base do site. routes - rotas avaliadas. projectId - GUID copiado no passo anterior.
